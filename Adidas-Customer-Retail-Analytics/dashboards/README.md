# Dashboards – Adidas Customer Retail Analytics

This folder contains dashboard screenshots created using Power BI.
Since the Power BI (.pbix) file is not available, dashboards are shared as images.

## Dashboards Included

### 1. KPI Dashboard
- Customer churn rate
- Retention rate
- Repeat purchase rate
- Customer Lifetime Value (CLV)

### 2. Loyalty & Promotion Impact
- Impact of promotions on purchase behavior
- Average order value with and without promotions

### 3. Store & Channel Insights
- Performance comparison across store types
- Online vs offline channel insights

### 4. Customer Segmentation
- Segmentation of customers into churned, repeat, and high-value customers
- Loyalty tier analysis

### 5. Recommendations
- Business recommendations based on dashboard insights
